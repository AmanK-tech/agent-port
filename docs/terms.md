# Terms of use

Agent Port is open-source software distributed under the MIT License and provided without warranty.
Users are responsible for reviewing restore plans, keeping destination backups, protecting archives,
and confirming that supported harnesses are closed before mutation.

Agent Port does not guarantee compatibility with undocumented or unsupported harness schemas. It
refuses unknown versions rather than attempting a best-effort mutation. Native sessions restore
only into the harness that created them.

Use Agent Port only with data and machines you are authorized to access.
